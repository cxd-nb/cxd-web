# CXD 个人网站

一个现代化的个人作品集网站，展示个人技能、项目经历和荣誉成就。

## 🌟 项目简介

这是一个响应式的个人网站，采用现代化的设计风格，包含以下主要功能：

- 🏠 **首页** - 个人介绍和导航
- 🏃 **运动** - 运动相关内容展示
- 💼 **项目** - 个人项目作品集
- 🏆 **荣誉** - 荣誉奖项展示
- 🛠️ **技能** - 技能专长展示
- 📧 **联系** - 联系方式和表单

## 🎨 设计特色

- **响应式设计** - 适配各种设备屏幕
- **深色模式** - 支持明暗主题切换
- **现代化UI** - 采用卡片式布局和渐变效果
- **流畅动画** - 平滑的过渡和交互效果
- **中文本地化** - 完整的中文界面

## 🛠️ 技术栈

- **HTML5** - 语义化标签结构
- **CSS3** - 现代样式和动画
- **JavaScript** - 交互功能和动态效果
- **Font Awesome** - 图标库
- **Google Fonts** - 字体系统

## 🚀 快速开始

1. 克隆项目到本地：
   ```bash
   git clone https://github.com/your-username/cxd-web.git
   ```

2. 进入项目目录：
   ```bash
   cd cxd-web
   ```

3. 在浏览器中打开 `index.html` 文件即可查看网站

## 🎯 功能特性

### 导航系统
- 固定顶部导航栏
- 响应式菜单（移动端适配）
- 活跃页面高亮显示

### 主题切换
- 明暗主题一键切换
- 主题偏好本地存储
- 平滑的主题过渡动画

### 页面内容
- **首页** - 个人介绍、技能标签、快速导航
- **运动** - 运动经历、成就展示
- **项目** - 项目作品、技术栈说明
- **荣誉** - 获奖记录、证书展示
- **技能** - 技能分类、熟练程度展示
- **联系** - 联系方式、留言表单

## 📱 响应式设计

网站采用移动优先的设计理念，在不同设备上都有良好的显示效果：

- 📱 手机端 (< 768px)
- 💻 平板端 (768px - 1024px)
- 🖥️ 桌面端 (> 1024px)

## 🎨 自定义

### 修改主题颜色
在 `css/style.css` 文件中修改 `:root` 变量：

```css
:root {
    --primary: #66ccff;      /* 主色调 */
    --primary-dark: #3ab8f5; /* 深色版本 */
    --primary-light: #99ddff; /* 浅色版本 */
    /* 其他变量... */
}
```
